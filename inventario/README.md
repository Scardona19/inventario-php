# Sistema de Inventario

Aplicación web desarrollada en PHP y MySQL para la gestión de inventario.

## Funcionalidades
- CRUD de productos
- CRUD de categorías
- CRUD de proveedores
- Control de movimientos

## Tecnologías
- PHP
- MySQL
- JavaScript
- CSS
- GitHub

## Base de Datos
El proyecto incluye el archivo SQL para importar la base de datos.
